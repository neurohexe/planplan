План-факт на мини-ПК — временный доступ Азамата

Этот комплект подготовлен для azamatikramov. Работоспособность входа с компьютера Азамата ещё нужно проверить после выдачи SSH-роли и её доставки на мини-ПК.

Перед запуском:
1. Подключитесь к корпоративной сети или VPN.
2. Должны быть настроены личные SSH-ключи/Skotty и персональный доступ CAuth к zomb-vodeyko-132.zombie.yandex.net. Код приложения не является паролем SSH.

Mac: запустите open-plan-fact.command. Если после передачи файл потерял право запуска, выполните в терминале: sh /путь/к/open-plan-fact.command
Windows: запустите open-plan-fact.cmd. Используется установленный OpenSSH.

После успешного SSH-входа откройте http://127.0.0.1:18768/
Логин приложения: azamatikramov
Личный код для мини-ПК передаётся отдельной закрытой карточкой. Код старого стенда на Mac для этого входа не подходит.

Пока окно подключения открыто, туннель работает. Для отключения нажмите Ctrl+C. При потере сети запустите файл снова. Mac владельца для этой схемы не требуется.

При первом соединении SSH предложит проверить ключ мини-ПК. Проверенный через существующее доверенное соединение отпечаток ED25519: SHA256:L/kEN6YWFXkMhb8M9m41f9+VPbcIX8kT8juJUtph8CY. При Permission denied (publickey) сначала нужно проверить SSH-роль, ключи и их доставку. При Address already in use проверьте, не запущен ли уже этот туннель.

Скрипты открывают порт только на 127.0.0.1 компьютера Азамата и не содержат паролей или чужих SSH-ключей.
