## Обоснование

Повторить на офисном мини-ПК `zomb-vodeyko-132.zombie.yandex.net` уже работающую
на Mac схему Tunneler для «План-факта», чтобы восемь коллег пользовались
HTTPS-ссылкой независимо от ноутбука владельца. Приложение на мини-ПК уже
работает на `127.0.0.1:18766`, с личными кодами и ролями. Запрошен исходящий
доступ из офиса; пользователи приложения работают из корпоративной сети/VPN.

Точные отправленные тексты и параметры сохранены в `tunneler-443.json` и
`tunneler-2022.json`. У Puncher ограничение комментария 1024; первая попытка
443 была явно отклонена с `comment_too_large` и не создала заявку. После
сокращения текста обе заявки созданы успешно, без повторов с неизвестным исходом.
