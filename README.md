# План-факт: автономная HTML-страница DataLens

Пользовательская инструкция: [ЗАГРУЗКА.md](ЗАГРУЗКА.md). Загружаемые файлы находятся в `dist/`.

Исходник интерфейса — копия `planfact-task42/app` от 10.11.2026. Неизменённые файлы и SHA-256 находятся в `src/vendor/manifest.json`. `tools/build.mjs` явно применяет изменения для DataLens; рабочий исходник и стенд не затрагиваются.

## Сборка

Нужен Node.js 22+. Зависимостей для сборки и работы HTML нет.

```sh
node tools/build.mjs
node tools/build.mjs --snapshot /path/to/рабочий-файл.csv --output /path/to/План-факт-обновлённый.html
```

Сборщик проверяет неизменность исходников, использует единый парсер CSV/JSON и отклоняет HTML больше 10 МиБ. JSON встраивается с экранированием `<`, U+2028 и U+2029. Размер рабочего снимка ограничен 5 МиБ самим приложением; это не утверждение о размере, который согласится скачать оболочка DataLens.

В HTML нет внешних ресурсов, обращений за данными, браузерного постоянного хранилища, нативных отправок форм или системных confirm/prompt. Поля сгруппированы в `div[data-pf-form]`, проверяются через Constraint Validation API и вызывают обработчики внутри документа. Подтверждения — обычные DOM-диалоги. Ссылки используют `OPEN_URL`, скачивание — документированный `EXPORT` с MIME `text/csv`.

Изменения касаются способа хранения, ввода и экспорта, а также найденных ошибок: двойного учёта частично оплаченного прогноза в обзоре/снимке закрытия и округления копеек в экспорте/редакторе. Сетевые ветки исходного приложения недоступны в интерфейсе, любые оставшиеся точки входа явно завершаются ошибкой `networkDisabled`.

## Проверка

```sh
node --test tests/domain.test.cjs tests/runtime.test.cjs
PLANFACT_JSDOM=/path/to/node_modules/jsdom node --test tests/ui.test.cjs
python3 tools/validate_page.py --strict dist/*.html
```

UI-тесты используют **jsdom 26.1.0**. Это зависимость только для проверки, она не входит в HTML и не загружается при просмотре. В текущей рабочей среде установлена в `/tmp/datalens-planfact-qa/node_modules/jsdom`. Для отдельной среды её можно установить в выбранный временный каталог: `npm install --prefix /tmp/datalens-planfact-qa --ignore-scripts --no-audit --no-fund jsdom@26.1.0`.

Тесты запрещают сеть, постоянное хранилище, нативные окна и прямое скачивание. DOM и арифметика проверены; JSDOM не проверяет современную CSS-вёрстку, sandbox браузера или реальное принятие сообщения хостом DataLens.

`tools/validate_page.py` — неизменённый официальный валидатор из публичного репозитория DataLens. Источник и SHA-256 записаны в `verification/manifest.json`; лицензия источника Apache-2.0. `tests/fixtures/` содержит маленькие вымышленные OOXML для проверки парсеров, это не рабочие бюджетные шаблоны.

Окончательное подтверждение: загрузка HTML в DataLens, визуальный просмотр, реальные кнопки и скачивание/открытие рабочего CSV. Публикация в этой задаче не выполнялась.
