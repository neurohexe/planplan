## Замечания

1. Общесистемный systemd имеет статус `degraded` из-за единственного
   `NetworkManager-wait-online.service`: ожидание началось в 10:31:50
   и завершилось с кодом 1 в 10:32:50. Ethernet `enp86s0` успешно подключился
   позднее, в 10:33:29; тогда же NetworkManager сообщил `startup complete`.
   Текущее состояние сети: `connected (site only)`, `limited`.
   SSH с Mac работает. Проверка доступности произвольных внешних сервисов
   не проводилась.
2. Ссылка на Mac `http://127.0.0.1:18768/api/ready` возвращает
   `connection refused`: работающего локального SSH-туннеля для этой ссылки
   сейчас нет. Это отдельный путь доступа; HTTP непосредственно на мини-ПК
   отвечает. Туннель в рамках проверки не запускался.

Первоначальная попытка SSH в ограниченном режиме выполнения не разрешила
имя хоста. Проверка с разрешённым сетевым доступом успешно подключилась;
исходная ошибка сама по себе не указывает на неисправность DNS мини-ПК.
